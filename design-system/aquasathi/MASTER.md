# AquaSathi visual system

A mobile-first field logbook for shrimp farmers. The site should feel like a practical coastal farm notebook, not a generic analytics product.

## Visual direction

- Palette: mangrove green `#183C32`, shrimp shell coral `#C85F43`, pond leaf `#216B58`, salt-paper `#F1EDDF`, warm white `#FFFDF6`.
- Display type: Literata for page titles. Noto Sans plus Noto Sans Telugu and Noto Sans Devanagari for readable interface text.
- Content: one task per section, short action labels, plain descriptions, large reading values, and a clear difference between demo and measured values.
- Surfaces: warm paper with restrained borders, field-note lines and small coral marks. Avoid a row of identical white cards or bright blue/purple SaaS styling.
- Motion: subtle 150–250 ms opacity and vertical transitions only. Keep all content visible with reduced motion.

## Farmer usability

- Provide English, Telugu and Hindi display-language switching. Persist choice locally.
- Use simple descriptions alongside technical parameter names and units.
- Primary and navigation actions have at least 44 px touch height; mobile uses a labeled bottom navigation bar.
- Use explicit labels, keyboard focus indicators, high-contrast status text, and status words as well as color.
- Always label simulated readings. Never imply that a photo is analyzed or that general source guidance is a pond diagnosis.
